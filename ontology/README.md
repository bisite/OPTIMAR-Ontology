# Ontology folder

Contains the OPTiMAR ontology files. Each version is kept as a separate file (`OPTiMAR-vX.Y.ttl`) and released files are not modified afterwards; the latest version is the one to use for instantiation and development.

- `alignments/` contains the alignment module with SAREF core and the Open Energy Ontology. It is kept separate so that the core ontology does not import them.
